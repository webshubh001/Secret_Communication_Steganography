6-Layer Pipeline

How SecretVault Works

Every message passes through six security layers before being safely distributed across multiple images.

01

AES-256 Encryption

Your secret is encrypted with a randomly generated 256-bit AES key using CBC mode and PKCS7 padding.

→
02

SHA-256 Integrity

A SHA-256 fingerprint of the ciphertext is computed and embedded to detect any tampering later.

→
03

Data Splitting

Ciphertext is split into N equal chunks — one per cover image — so no single image reveals anything.

→
04

LSB Steganography

Each chunk is hidden inside a cover image using Least Significant Bit embedding — invisible to the human eye.

→
05

Face Authentication

Recipients must pass biometric face authentication (128-d embeddings via dlib) before decoding.

→
06

Reconstruction & Decrypt

Chunks are extracted, verified, reconstructed, and AES-decrypted to recover the original secret.

Why SecretVault

Enterprise-Grade Security Features

Zero Knowledge Storage

Raw images and plaintext are never stored. Only face embeddings and encrypted keys are persisted in the database.

Tamper Detection

SHA-256 hashes at chunk and full-payload level detect any modification to stego images before decryption.

Distributed Security

Data is split across 2–5 images. An attacker who intercepts fewer than all images learns absolutely nothing.

Biometric Authentication

128-dimensional face embeddings via dlib ensure only the authenticated recipient can decode their messages.

Rate Limiting

All sensitive endpoints are rate-limited to prevent brute-force and enumeration attacks.

Quality Metrics

MSE, PSNR, and SSIM scores are computed for each stego image to quantify steganographic imperceptibility.
